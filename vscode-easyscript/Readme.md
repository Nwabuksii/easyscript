# easyScript for VS Code

Syntax highlighting and file icons for [easyScript]

- `.ej` — easyJavaScript
- `.et` — easyTypeScript

## Features
- Full keyword highlighting for all easyScript keywords
- String, template literal, comment, and regex highlighting
- Custom file icons for `.ej` and `.et`
- Bracket matching and auto-closing pairs

## Setup
After installing, select **easyScript Icons** from the file icon theme picker
(`Preferences: File Icon Theme`) to see the custom icons.
