# easyScript

A human-readable language built on JavaScript and TypeScript.
Readable keywords, full access to the Node.js ecosystem.

## Install

Download `easyScript-Setup.exe` from the [latest release](../../releases/latest)
and run it. Then from any terminal:

    esx my-script.ej

## Syntax

See [Documentation.md](Documentation.md) for the full keyword reference.

## Run from source

    bun run esx.js my-script.ej
